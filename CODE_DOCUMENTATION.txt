PROJECT OVERVIEW
================================================================================
This is a responsive product landing page for "Mangalam HDPE Pipes" built with
vanilla HTML, CSS, and JavaScript. The site showcases HDPE pipe products with
detailed specifications, manufacturing processes, and customer testimonials.

TECH STACK:
- HTML5 (semantic markup with accessibility attributes)
- CSS3 (responsive design, animations, grid/flexbox layouts)
- Vanilla JavaScript (no frameworks/libraries)
- Responsive Design: Mobile-first approach (breakpoints: 360px, 600px, 800px, 1080px, 1200px)

TECHNICAL HIGHLIGHTS
================================================================================

Performance Optimizations:
- Passive event listeners for touch/scroll events
- requestAnimationFrame for smooth animations
- Intersection Observer API instead of scroll events
- CSS transforms for GPU-accelerated animations
- Debounced resize handler (80ms)

Browser Compatibility:
- Modern browser features (CSS Grid, Flexbox, custom properties)
- Graceful degradation for older browsers
- Touch event support for mobile/tablet
- Keyboard navigation as primary fallback

Maintainability:
- CSS variable system for theme changes
- Modular JavaScript functions
- Semantic class naming (BEM-like convention)
- Reusable utility functions
- Clear separation of concerns

Accessibility Compliance:
- WCAG 2.1 Level AA standards
- Keyboard-only navigation support
- Screen reader friendly markup
- Focus indicators visible
- Proper ARIA usage
